# Mini Bezier Shaper

用一條可以拖的貝茲曲線，即時塑形網格的一排點或整撮頭髮。
Shape a row of vertices, or a whole hair strand, with a live Bezier curve.

## 安裝 / Install

- Blender 4.2 以上：用 `mini_bezier_shaper_4.2+.zip`
  偏好設定 → 附加元件（Add-ons）→ 右上角下拉選單 → 從磁碟安裝（Install from Disk）
- Blender 3.0 到 4.1：用 `mini_bezier_shaper_legacy.zip`
  偏好設定 → 附加元件 → 安裝（Install）→ 選 zip → 勾選啟用

## 用法 / Usage

1. 在網格編輯模式選取要塑形的部分。
2. 按 N 打開側邊欄 → Edit 分頁 → Mini Bezier Shaper。
3. 選模式：
   - 整撮髮束 Whole Strand：選整撮頭髮（或管子、髮片），整撮沿曲線一起彎。
   - 單排點 Single Row：選一排相連的點，點會貼到曲線上。
4. 設定控制點數，按「建立塑形曲線」。
   - 髮束已經彎過（例如先往旁邊再往下）時，勾選「沿截面找中心線 Follow Rings」。
     需要根部開口或根部那圈不選；找不到時會自動改用簡單方向。
5. 用 G 拖控制點、拖把手，網格會即時跟著變。
6. 按「完成塑形」保留形狀，或「取消塑形」還原。

### 整理髮束 Tidy Strand

拉點、用 R 轉角度把截面弄歪了，用這個一鍵修好：

1. 選整撮髮束。根部要是開口，或根部那圈不要選（當作固定基準，不會動）。
2. 按「整理髮束」。每圈截面會變成整齊的圓、點平均分佈，粗細和走向也會變平順。
3. 左下角面板可調：
   - 圓度 Roundness：1 是正圓，0 是只順走向、不改截面形狀（扁髮片用 0）。
   - 平順 Smooth：數字越大，走向和粗細變化越平順（太高會把粗細變成直線收細）。
   - 解開扭轉 Untwist：從根部往髮尖對齊每一圈，修掉多角度用 R 旋轉造成的扭轉（預設開啟）。

### 平順扭轉 Smooth Twist

扁髮片扭得不平均、看起來像折到時用。每圈截面的形狀和位置都不變，
只繞著髮束轉一點角度，讓扭轉從根部到髮尖平均分佈。根部和最後一圈不會動。

1. 選整撮髮片（根部開口，或根部那圈不選）。
2. 按「平順扭轉」。
3. 覺得改太多，在左下角面板把「強度 Strength」調低。

Blender 介面設成繁體中文時，按鈕會顯示中文。

## 小提醒 / Notes

- 髮束模式最適合大致朝同一方向的髮束；彎成 U 字回頭的髮束，先分段做比較準。
- 選的點很多（上千個）時，拖曲線可能會稍微卡。
